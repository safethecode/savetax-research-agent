# 소액 표준 하드웨어 조사

WD WUH722020CLE6L4 20TB에서 제출 가능성이 있는 가격을 찾았다. 공식 대회 API는 `available`이며, 두 납품요구의 합계는 7대, 12,852,000원이다. 각 단가는 1,836,000원이므로 배송·세금 포함 비교가가 1,530,000원 이하면 대회 가격차 기준을 충족한다.

메모리올의 실제 판매 페이지에서 같은 전체 모델명, SATA, 20TB, 3년 A/S 박스 제품, 가격 1,456,000원, 재고 있음, 배송비 2,750원, 회원·비회원 이용 가능을 공유 브라우저로 확인했다. 부모 담당자는 일반 소비자 표시가이고 별도 VAT 추가 문구가 없다는 점, 다나와의 입점 기준을 보조근거로 종합하여 VAT 포함 비교가로 채택했다. 판매처가 VAT 포함을 명시했다고 주장하지 않는다. **부모 담당자가 공식 preview 뒤 실제 제출했으며, 절감 가능액 2,640,750원이 접수됐다. 후속 lint는 대기 상태다.**

[가격비교에 표시된 메모리올 현금가](https://prod.danawa.com/info/?pcode=94815101)와 [직접 확인한 판매 페이지](http://memoryall.co.kr/product/productView.php?nProdCode=94815101&service_id=pcdn)를 함께 기록한다. 판매처 HTTPS 접속이 실패하여, 점수용 HTTPS 출처로는 실제 판매가와 같은 금액이 표시된 다나와 페이지를 사용하도록 초안을 준비했다. 쇼핑몰 자체의 VAT 포함 명시 문구는 확인하지 못했으므로 그 한계를 본문에 공개한다.

배송비를 매 대당 2,750원씩 보수적으로 더한 채택 비교가 1,458,750원으로 계산한 두 fact의 절감 가능액 합계는 2,640,750원이다. 이 금액은 대회 비교 기준의 금액이며 실제 예산 집행이 바뀌었다는 뜻은 아니다. 조달품은 현장설치도인 선택부품으로 하자보수 2년이 포함된다. 판매 가격은 HDD 단품 취득 범위이며, 장비 장착·설정 서비스 포함 여부는 확인되지 않았고 관측된 별도 설치비도 없다.

이번 표본은 데이터 `20261010-r5`의 고정 순서 `MD5(삼손:20261010-r5:item_id), item_id`에서 250000~300000 구간을 우선하고 100000~300000으로 확장했다. 이후 원래 담당하던 50000~100000 구간의 남은 표준 모델도 추가 선별했다. 기존 모든 공개 연구 JSON에 있는 물품 ID를 제외하고 공식 targeted lookup에서 `available`인 물품만 새 가격조사에 사용했다.

가까웠던 모니터 두 건은 다음 이유로 보류·제외했다.

- LG 22U403A, 물품 26120314: 공식 단가 154,000원. 컴퓨존 검색·추출에는 125,000~125,500원과 129,000원이 보였지만, 현재 실제 HTTP 원문과 브라우저는 가격을 숨기고 ‘사업자 회원 전용’으로 표시한다. 이를 현재 일반 현금가라고 채택하지 않았다. 일반 소매 단서 129,440원에 배송 4,000원을 더하면 가격차 기준에 미달한다.
- LG 24BA400, 물품 25864153: 공식 단가 233,000원. LG 192,000원은 일시품절, 전자랜드 189,000원은 SOLD OUT, 피씨토피아의 검색 가격 191,400원은 현재 페이지에서 구매 불가로 바뀌었다. 11번가 상품 9256680464도 실제 브라우저에서 현재 판매 중이 아님을 확인했다. 다나와 현재 표시가는 235,140원으로 기준에 미달한다.

이외 가격조사 17건의 결과와 출처는 `hardware-small.json`에 남겼다. 이동식 스탠드 패키지의 모니터 단품 가격, 중고 모니터·카메라, 본품이 아닌 백라이트나 렌즈 어댑터의 다른 구성을 같은 제품 가격으로 취급하지 않았다. 전체 평균이 아니라 개별 scorable fact의 최고 단가도 확인했다. 대회 기준은 `P >= 1.2 × B` 또는 `P - B >= 1,000,000원`이며, 선택한 양수 범위의 `floor(C - B × Q)`만 계산한다. 사용자 지시에 따라 납품요구일과 현재 소매가의 시점 차이는 제외했다.

API 원문 전체 facts는 비공개 작업 경로 `work/hardware-small`에 보관했다. 공개 연구에는 데이터 출처·버전, 합계, 대표 사실과 직접 관측 근거만 보존했다. 점수 API POST는 담당 부모 에이전트가 수행한다.

추가 조사에서는 로지텍 VR0038(MeetUp 2), 엡손 DS-770II·네트워크 패널, 캐논 XA65, WD 10TB·4TB SAS, 솔텍과 이지넷 스위치·광모듈 등을 공식 개별 fact 기준으로 확인했다. 4TB SAS HUS726T4TAL5204의 하이마트 369,000원은 구캐시 단서로만 남아 현재 판매 여부를 부모 담당자가 확인 중이다. 다른 후보는 신품 가격차 기준 미달, 단종·품절, 정확모델 가격 부재로 미제출했다. Parallel은 독립 후보 5개씩 동시에 검색했고, 반환된 유사모델·해외리퍼·무관상품을 실제 상품 페이지와 대조해 제외했다. 현재 추가 점수 확정 후보는 없다. 상세 결과와 공식 Q/C 합계는 JSON에 추가했으며 API 전체 원문은 비공개 work 경로에만 보존했다.
