# 신규 고액 자재와 보관 후보 재검토

## 아스콘 23734462

공식 상세는 WC-2 가열 3등급, 1,763개 fact, 429,799톤, 비교금액 62,781,539,545원이다. 전체 계약·납품요구·라인 번호는 [JSON](root-material-frontier-20261017.json)에 보존했다. 원시 계약의 인도 조건은 공사현장하차도이고 해당 등재의 최소 요구 수량은 25톤이다. 현재 관측에서는 다른 참가자의 반려 뒤 등록 제한 중이며 2026-10-17 02:48 KST 이후 상태 재확인이 필요하다.

[케이토목 실제 판매 상세](https://ktomok.com/shop/item.php?it_id=1581999319)를 HTTP·브라우저와 연결 이미지로 읽었다. #78 표층용 골재 최대 13mm, 75,000원/톤이며 부가세·운반비 별도다. 발주 시 전화문의 안내와 수량 입력이 있으나 연락·장바구니·구매는 하지 않았다. 지역별 화물운임·하차비와 실제 공급 범위는 미확인이다. 공통 상세 이미지는 별도의 등급 시험 자료를 제공하지 않는다.

13mm 표층용이라는 설명만으로 WC-2 3등급에 맞는다고 확정하지 않았다. 표시가에 VAT만 더해 C에서 뺀 산술 차액 약 273.23억 원은 등급·운임·하차·공급 지역을 반영하지 않은 값이다. 비교 단가·제출 예상액·목표 달성액으로 채택하지 않았다.

## 주성 J-ALF-4T, 24838799

공식 상세는 28개 fact, 35,882㎡, 비교금액 2,543,874,348원이며 현재 available이다. 원품 명칭은 4mm 평판이고 인도 조건은 납품장소하차도다. 이 명칭만 보고 범용 복합 원판 가격을 대입하지 않았다.

실제 HWP 11,239,424바이트를 내려받아 읽었다. SHA256은 `b3df2dae1a4781d5ae356bda6c5030c47d4b8c73ccf5bc4a41ddf9e03584a157`이다. 해당 모델은 **알루미늄 성형 코어·불연**이며 불소수지 마감, 지바 A6063/T5와 AL 리벳이 명시된다. 공식 속성의 전체 두께는 30mm다. 원문에서 꺼낸 상·하부 사진에서도 절곡 테두리와 부자재가 보인다. HWP 텍스트와 실제 사진을 읽은 범위이며 전체 문서의 페이지 렌더 검토를 완료했다고 표시하지 않았다.

범용 PE/무기질 FR 코어의 4T 평판, 절곡·지바·리벳을 제외한 원판값은 이 완성 가공품의 비교 단가로 채택하지 않았다. 기존 SER-AL-I의 원규격을 전용하지 않고 이 모델의 원문에서 별도로 확인했다.

## 철근과 캡슐 세제

고액 미기록 후보 20개의 표적 lookup 결과는 available 12개·claimed 6개·on_hold 2개다. 검색된 철근 뉴스 시세·잔재 가격과 실제 일반 판매가격을 구별했다. 한국철근거래소는 TLS 인증서 검증 단계에서 실패했으며 인증 검증을 우회하지 않았다. 도소마켓은 HTTP 200이지만 초기 카테고리 선택 화면이어서 검색의 870원/kg을 실제 선택가로 채택하지 않았다.

보관된 군용 캡슐 세제 25667205는 현재 타참가자 claimed로 바뀌었다. 이전에 13.15억 원 시나리오가 있었던 다이소 1072759도 실제 재조회에서 택배 일시품절이다. 신규 제출하지 않고 이전 조사 결과와 현재 제외 사유를 함께 보존했다.

root는 사용자가 지정한 SaveTax 검색 화면도 직접 읽고 계약 단가 정렬을 확인했다. 화면의 클라우드 계약 상한 금액이나 분석 글을 판매 근거·납품 비교금액으로 쓰지 않았다. 수량·금액 계산의 기준은 계속 공식 fact다.
