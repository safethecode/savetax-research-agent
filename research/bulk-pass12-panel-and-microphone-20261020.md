신규 원품 카탈로그2종, REX-580D 전체41facts, 실제 Parallel7쿼리·HTTP5건·제조사 이미지3개·Jev1회를 구분해 보존했다. 채택 단가와 검증 절감액은 모두 `null`, POST는0건이다. 상태 조회나 검색 결과만 있던 항목을 실독 완료로 세지 않았다.

- **25509095 CM-SA20-C**: 부모가 실제 내려받은211만 바이트 HWP와 새 공식 카탈로그를 대조했다. 식별번호·모델·1000×1000×35mm·A1050P2mm·불소수지가 일치한다. 1㎡당 판1EA, SK5M 더블4클립2.66EA, SGCC 체결판2.66EA, 피스5EA, ABS패킹1EA가 명시된다. 원품은 절곡·배수홈·전용 결합을 갖춘 완성 패널이다. 실제 조은데코 JENTLEE 제조사 페이지와 시공 이미지도 읽었으나 같은 모델의 고정 일반 판매가는 없다. 다른 세라믹 시트나 원판 가격을 완성품 가격으로 바꾸지 않았다. 본인 G2B 브라우저는 본문·첨부가 비어 실패했고, 부모의 별도 다운로드 성공과 구별했다. 원문은 변경추적 미평가 HWP이며 전체 표·도면의 시각 검수 완료는 아니다.
- **24089737 REX-580D**: 이룸시스 실제 본문은 정확 한양전자산업 송신기를1,050,000원으로 표시한다. 새 공식41facts·601대·631,050,000원의 개별 단가도 모두1,050,000원이다. 세금과 배송을0으로 놓아도 이 판매처에서 양수 차액은0이다. JSON-LD의 `valueAddedTaxIncluded:false`와 화면의 직접 세금 문구 미확인은 구별했다. Jev는 실제 DONE을 반환했지만 이를 모든 구성·구매 조건의 검증 완료로 확대하지 않았다. 전체 계약·납품요구·라인과 Q/C를 JSON에 보존했다.
- **25206275 SSM-P001**: 실제 AMOSENSE 공급자 원문은 두 화자의 위치에 기반한 음성 분리와 디지털 MEMS 배열을 설명한다. 가격은 `Depend on quantity`, MOQ20이다. 같은 주파수의 단순 마이크·MEMS 부품·다른 SSM 모델 가격은 쓰지 않았다. 공식 카탈로그와 공급자 설명의 지향성 표현 차이도 유지했다.
- **24564962 민속 맛김치5kg / 24600738 다경 맛김치10kg / 23383856 DNR20X**: 추가 검색은 다른 제조원·원산지의 김치,3kg 기본가, 다른 NR20X와 가격비교를 반환했다. 정확 제조사·모델의 실제 일반 판매 조건을 닫지 못했으며 검색 단서 단계로 남겼다. 쿠폰·월렌탈·다른 포장과 부품 가격으로 절감액을 만들지 않았다.
