# Pass9 판매 원문·비교 범위 확인

이 묶음에서 새 카탈로그 8품목, 상태 조회 5품목(모두 available), Parallel 15개 검색, HTTP 9개 페이지를 확인했다. 이 중 8개는 본문을 읽었고 삼성 판매처 1개는 HTTP 200이지만 본문이 비어 있었다. 새 공식 fact 조회·채택 단가·검증 절감액·POST는 모두 없다. 카탈로그의 납품 합계는 탐색 자료이며 공식 fact의 C/Q를 대신하지 않는다.

사운드파워의 MIPRO MA-100SB에서 **앰프본체 + 헤드셋 마이크**를 실제 선택했다. 기본 700,000원에 옵션 55,000원이 추가되어 수량 1의 표시 합계는 **755,000원**이었다. 보이는 구매 버튼과 60,000원 이상 무료배송 문구를 읽었고, 전용 bulk 세션의 임시 탭 정리를 확인했다. 기본가의 공개 HTML 분해는 공급가 636,364원과 세액 63,636원이다. 옵션의 별도 세액 분해를 직접 확인한 것은 아니다.

이 가격은 DS-900DA의 채택 단가가 아니다. 원품의 마이크 2개 지원과 전관방송 수신·앰프·스피커 일체형 기능에 대한 대응을 확인하지 못했으므로 비교·절감액은 null로 보존한다. 50W RMS만으로 전체 핵심 성능이 우수하다고 판정하지 않았다.

베가비티입제는 공식 사진의 1kg/25g×40포와 유효성분을 확인했지만 일반 판매가는 찾지 못했다. YS-1은 586kg/개·1.67개/㎡·압축강도 28MPa 이상인 대형 컬러 블록이며 작은 민무늬 블록 가격을 전용하지 않았다. SHA-PS01은 원형 송풍 팬과 분무 노즐이 있는 완제품으로 확인되어 펌프·호스 부품과 구별했다.

보디가드의 실제 판매가는 1L 18,500원이었고 원품의 5L×4통과 다르다. 한미타월의 새 저가 목록은 물수건·면행주·손수건이었다. 원품 180g 타월의 가격으로 쓰지 않았다. LED 검색의 8W 모듈·중고 50W도 신품 완성 조명 가격에서 제외했다.

삼성 판매처의 브라우저 읽기는 document.readyState 시간 초과로 실패했다. 본인 세션의 기준 탭을 복원한 뒤 다른 판매처에서는 실제 옵션 합계 읽기에 성공했다. 접속 실패를 시장 최저가 확인이나 품절로 해석하지 않았다. HGS-HG815S·GC180·일반 샤워타월은 현재 읽은 범위와 미완료 사유를 JSON에 구분했다.

JSON에는 13개 품목 카드와 원문 파일의 크기·SHA256이 있다. 이 묶음에 새 fact가 없으므로 계약·납품요구·라인을 갖춘 제출 준비본으로 표시하지 않는다. 고수량 4개 후속 품목은 별도 원문으로 이어 조사한다. 고정 후 원천을 덮어쓰지 않는다.
