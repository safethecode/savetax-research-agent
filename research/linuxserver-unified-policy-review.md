# Linux 백신 신규 서버 라이선스 정책과 실제 구입단위 — 추가 검토

이 문서는 기존 121,000원/서버 보수 검토본을 고치지 않은 추가 연구다. **공식 preview·접수·채택액은 모두 0**이며 새 가격을 적용한 점수 본문을 제출하지 않았다.

[제조사의 2026-05-07 공지](https://www.bitdefender.com/en-us/blog/businessinsights/whats-new-in-gravityzone-may-2026)는 2026-05-11부터 GravityZone Business Security 등의 신규·갱신 라이선스에서 서버 비율 제한을 없애고 모든 PC·서버를 endpoint seat로 센다고 설명한다. 현재 비교 페이지에 남아 있는 서버 30% 설명과 충돌하는 내용을 날짜와 함께 보존했다. [국내 동일 상품37](https://www.bitdefendershop.co.kr/product/business.asp?productNo=37)은 1년 신규 전자발급과 Linux 지원을 표시한다. 이를 신규 정책 대상이라고 해석하지만 실제 발급 키나 활성화 화면을 관측한 것은 아니다.

실제 국내 가격 계산기에서 **1년·5~100개 모든 정수 수량 96개**를 직접 입력해 표시 합계와 구매 표시를 읽었다. 5개 이상 1개 단위이며 101개 입력은 100개로 제한된다. 5개 배수로만 살 수 있다는 가정은 쓰지 않는다. VAT 포함 단가는 5~20개 24,200원, 21~50개 23,100원, 51~99개 22,000원, 100개 19,800원이다. 6개 145,200원·7개 169,400원·100개 1,980,000원 등 실제 선택 합계를 보존했다. 주문·장바구니·지원 신청은 하지 않았고 임시 탭도 정리했다.

[공식 관리 문서](https://www.bitdefender.com/business/support/en/77209-98153-license-management.html)는 새 기본 키가 기존 키를 대체하며 seat 수를 자동 합산하지 않는다고 경고한다. 다만 [제조사 직원의 공개 답변](https://community.bitdefender.com/en/discussion/99505/lizenznutzung-verwaltung-von-produkten)은 키 병합이 가능하고 공식 구매는 제조사 지원, 파트너 구매는 파트너를 통한 절차라고 설명한다. [응답자의 프로필](https://community.bitdefender.com/en/profile/Andrei_S%20Enterprise)도 Business Support Manager·BD Staff로 확인했다. 국내 판매처의 실제 병합 처리·기간·추가비는 확인하지 않았으므로 자동 병합·무료 처리·이미 활성화한 권리라고 주장하지 않는다.

각 사실 Q가 100 이하이면 max(5,Q)개의 실제 표시 합계를 쓴다. 100 초과이면 100개 구입단위를 반복하고 잔여가 있으면 최소 5개 이상으로 더하는 **비용 계획**을 따로 둔다. Q=104라면 관측한 100개+5개를 구입하는 계획으로 1개 남는 seat도 부담한다. 서로 다른 사실의 남는 seat는 합치지 않는다. 추가 seat로 더 싸게 최적화할 수 있는 경우도 이번 단순 산식에서는 적용하지 않았다.

신규 정책 열은 각 사실의 구입계획 비용/Q를 소수 여섯 자리까지 올림한 뒤 floor(C−BQ)를 합산한 조건부 값이다. 단일 주문 범위와 키 병합이 필요한 복수 주문 계획 범위를 JSON에서 분리했다. 네 물품 합계는 **5,363,161,165원**으로, 접수·채택액과 합산하지 않는다.

일반 Linux 서버 악성코드 방역 1년의 핵심 목적과 유료 소프트웨어 구성을 비교한다. 원품과 대안의 지원 OS·자원, Docker/메모리 사전검사·GS·EPP·현장설치·4시간 응답·교육 차이는 유지한다. 실제 기관별 환경·설치·이전비까지 검증됐다는 뜻은 아니다. [공개 JSON](linuxserver-unified-policy-review.json)은 전체 501개 계약·납품요구·라인과 Q/C·단위·세금·기간, 각 주문 계획·실제 관측 가격·여섯 자리 올림 산식, 원문 해시를 포함한다. 기존 원본 문서와 판매 원문은 private 자료로만 보존한다.
