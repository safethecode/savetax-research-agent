# 1,000억 원 목표의 대량 자재 보관 후보 검토

신규 제출 준비 완료는 **0건·채택 예상액 0원**이다. 보관 기록에서 10억 원 이상 산술이 가능한 패널 4건을 먼저 분리했고, 기존보다 두꺼운 심재·외피를 선택할 수 있는 새 판매품을 찾았다. 아래 금액은 성능과 운송 조건을 맞추기 전의 조건부 계산이며 접수액이나 검증 완료 절감액에 더하지 않는다.

사용자가 제시한 현재 110억 원에서 목표 1,000억 원까지 남은 890억 원을 50회로 나누면 필요한 평균은 **17.8억 원/회**다. 현황·잔여 한도는 공식 API로 재확인해야 한다.

## 새로 찾은 상향 사양 선택 경로

[비드앤비 GW48 내화1시간 RP1000](https://bidnbee.com/shop/1784600924)의 실제 HTML은 기본 **125T·35,310원/m**, 외피 **0.6T/내피0.5T 추가 2,200원/m**을 표시한다. 원품 100T·0.5T/0.5T보다 심재와 외피가 두꺼운 구성을 선택할 수 있다. 복구된 bulk 독립 native에서 **125T·0.6T/0.5T·외부 백색·내부 백색·길이 2000mm를 실제 선택한 뒤 수량 1·총 75,020원**을 확인했다. 구매·장바구니는 실행하지 않았고 임시 탭·작업 잠금을 정리했다.

대안 [GW64 RP1000](https://bidnbee.com/shop/1671003908)은 125T·0.6T/0.5T 또는 PVDF 백색 외부 색상 옵션이 있다. 세 구성은 각 판매품의 실제 옵션 금액으로 계산했으며 서로 다른 상품의 기본가를 섞지 않았다.

| 조건부 구성 | HTML 산술상 2㎡ 한 장 | 229개 기존 fact의 양의 차액 합계 |
|---|---:|---:|
| GW48 내화1시간 명칭, 125T·0.6T/0.5T | 75,020원 | 2,763,865,260원 |
| GW64 불연 명칭, 125T·0.6T/0.5T | 77,660원 | 2,558,547,178원 |
| 위 GW64에 PVDF 백색 외부 색상 추가 | 89,760원 | 1,716,469,645원 |

각 fact마다 `ceil(Q/2)`장을 별도 구입하고, 비용/Q를 소수 6자리 올림한 뒤 `floor(max(C−B×Q,0))`를 합했다. 서로 다른 발주 사이의 남는 면적을 공유하지 않았다. 해당 계산과 원래 계약·납품요구·라인 번호는 `work/bulk-goal1000/scenario-1.json`부터 3개 파일에 보존했다. 첫 구성은 현재 공식 fact와 실제 선택 합계로 검산했고, 나머지 GW64 두 구성의 native 합계는 미관측이다. 성능·접합·운임을 맞추기 전이므로 세 금액 모두 미채택이다.

심재·외피의 명목 두께 증가만으로 단열·내풍압·방수·내화 성능이나 전체 제품의 우수성을 확정하지 않는다. 판매 상세도 공장별 품질 차이와 코일 두께·표면 형상에 따른 성능 차이를 안내한다. 새 내화 상품에 연결된 인증·성적서 이미지 **6개가 실제 GET에서 404**였으므로 제목의 ‘내화1시간’을 시험으로 확인된 성능으로 채택하지 않았다.

기존 [GW48 지붕 상품](https://bidnbee.com/shop/1671003950)에 연결된 내화·화재·열전도·흡음 이미지 4개는 실제 HTTP 200으로 받아 시각 검토했다. 내화 인정서의 SWG100T64K·SWG123T48K 등은 다른 두께·밀도 구성이다. 이 성적을 현재 GW48/250T 지붕이나 새 125T 선택 구성에 전용하지 않았다. 실제 원문과 해시는 work에만 두었다.

## 이번에 반복을 멈춘 경로

HN-684의 122.51억 원은 설치부·정량 하중 검증 전 산술이다. 같은 와이어망·더이로운 자료는 [기존 후속 검토](manhole-core-evidence-followup.json)에 이미 부정적 결과가 있어 추가 반복하지 않는다. BDK-SC-002의 11.49억 원도 일반 데크 완성 조합이 확인되지 않은 부분 부재 시나리오로 유지한다. 기존 소액 의자·수납장·블록은 이번 10억 원 기준을 충족하지 않아 먼저 제출하지 않는다.

보관 목록에서 SER-AL-I(24206901, 로컬 총액191.29억 원)와 SJ-CP04-0612(24595298,112.15억 원)는 상태 재확인 우선순위다. 제조사 자료는 내진 프레임·레일 기능을 설명하므로 저렴한 평판 가격만으로 완성 시스템 차액을 만들지 않는다. 새 제조사 페이지의 모델 대응은 인증된 공식 납품 fact를 대신하지 않는다.

## 복구 후 연속 조사

root가 인증·데이터셋·Mac 브라우저 런타임을 복구했다. 초기의 HTTP401·duckdb 미설치·AF_UNIX 경로 길이 실패는 당시 결과이며 현재 공통 차단으로 유지하지 않는다. `.env`는 허용된 환경변수 경로로만 읽고 키 값을 출력하지 않았다. 요청한 Downloads/AGENTS.txt도 키를 메모리에서 마스킹해 읽었다.

**Parallel 실제 검색 17회, Jev 실제 다음 동작 예측 1회**를 수행했다. Jev는 SELECT·232ms·jev-1.13.0을 반환했으며 실제 옵션 합계는 그 뒤 native에서 독립 확인했다. 이는 성능 검증 시간이나 시험 통과를 뜻하지 않는다.

복구된 `work/data/latest-20261017/full-catalog-priority.parquet`에서 owner 1·batch 200 이후의 C20억 원 이상 172행과 C10~20억 원 290행을 재선별했다. 보관 item_id 필드에 없던 고액 45행을 분리하고 추가 자재 키워드 7개를 골랐다. 전체를 웹 검토했다는 뜻은 아니다. 신규 자재 6개만 표적 lookup한 결과 available 4·on_hold 1·claimed 1이었다.

고액 보관 6개도 표적 재조회했다. **SER-AL-I(24206901)와 SJ-CP04-0612(24595298)는 available**, 인조잔디 4개는 claimed라 종료했다. 현재 공식 SER-AL-I는 72 facts·102,426㎡·19,129,475,500원이며 모두 하차도 listing0005다. 이름의 표면판 2mm와 별개로 실제 카탈로그 완성 치수는 **1800×900×30mm**다. 내진 기능과 가공형상을 일반 2mm 평판으로 지우지 않는다. SJ-CP04-0612는 36 facts·51,377㎡·11,215,276,016원이며 listing0019는 **현장설치도**다. 두 물품 108개 전체 계약·납품요구·라인과 현재 Q/C를 이번 JSON에도 보존했다.

새 [ALKorea 가격표](https://alkorea.com/000/estimate.htm)는 검색의 AL2T 100,000원과 달리 현재 **120,000원부터**이며 가공 20,000원부터·틀 35,000원부터·설치 50,000원부터를 따로 표시한다. VAT·운임·장비·실란트·단열·방수가 별도이고 구체 모델도 없다. 이 시작가표를 위 완성 내진 패널의 확정가로 채택하지 않았다. 스마일테크 제조사 HTTPS는 인증서 검증 오류가 나 검증을 끄지 않았다.

25102083 목제문은 available이지만 공식 단위가 개가 아닌 **㎡**다. 문짝 1200×2050×36mm·문틀 2400×2600×245mm·레일 포함·유리 별도인 양개 세트이며, 문짝과 철물 단품 가격을 전체 세트로 쓰지 않았다. 새 레미콘 3개는 available이지만 정확 제조사·규격·지역·운임을 맞춘 실제 판매 원문을 확보하지 못했다. 뉴스나 통계 단가를 판매 가격으로 채택하지 않는다.
