# 일조 공개 판매가 원천과 매핑 초안

관측: 2026-10-16T06:46:16.739218+00:00. 기존 엔진을 바꾸지 않은 연구 초안이다. 원시 CSV 5,828행은 work에만 보존했고, 와이어메쉬 34행의 공개 판매가·규격 표본만 연구에 남겼다.

공개 [와이어메쉬 페이지](https://www.iljo.net/page/sub7_7) HTML의 실제 `CSV_URL`은 [Google 공개 배포 CSV](https://docs.google.com/spreadsheets/d/e/2PACX-1vTZwRvNgSl_5jmYceUq06ocKP7CuhEbHSXc1iqmESOo485zj_D7NCcKsYsUs9nRQyW66SQ3SaM7WVra/pub?gid=0&single=true&output=csv)다. 인증 없는 GET HTTP200을 확인했다. 페이지는 이 CSV를 `parseCSV → buildData → render`로 읽는다. 직원용 잠금·매입가 조회·문의/견적 전송·주문 기능은 사용하지 않았다.

현재 저장 위치는 work/concrete-focus/iljo-public-prices-raw.csv, 공개페이지의 키 문자열을 가린 복사본은 iljo-wiremesh-public-page-sanitized.html이다. 원시 전체표와 페이지 코드를 공개 연구 파일로 복사하지 않는다.

기존 DSL은 savetax/rules.py의 v1 필터/정렬로 소매 원천 레시피가 없다. 전략은 strategies/*.json, 수동 관측 검증은 savetax/evidence.py, 접수 연결은 savetax/submissions.py에 있다. 이 문서는 별도 source recipe 초안이며 현재 validate_strategy에 바로 넣는 실행 가능한 전략이 아니다.

판매가 규칙: `최종판매가 ÷ 단위환산계수`를 10원 자리로 반올림한다. 실제 공개 JS는 `Math.round(price / mult / 10) * 10`이며 이전/전월 가격이나 매입가를 쓰지 않는다. 표시 가격은 VAT 별도다. 와이어메쉬 합계는 장 단위지만 공통 설명에 본당 문구도 있어 품목별 판매 단위 확인을 분리한다.

4.8mm와 5.0mm는 다르며 철선 단면적은 약7.84% 감소한다. #6 호칭만으로 같다고 하지 않는다. 1750×1750mm의 3.0625㎡는 외접판 면적이다. 판매처 면적 계산기는 겹침·손율 미반영을 명시한다. 안너비·철선수·자유단·현장 겹침을 모르면서 이를 실제 보강 면적으로 확정하지 않는다.
