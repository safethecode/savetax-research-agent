# 일반 판매 묶음과 고액 유제·항공유 후속 확인

이번 추가 접수는 0건이다. 계정의 비반려·비보류 59건 예상액은 31,585,078,909원, 약 315.85억 원이다. 최종 심사 인정액은 아니며 오늘 37회·전체 38회가 남아 있다. 기존 접수와 가격은 유지했다.

항공유·ILT-4·참치의 공식 917개 fact와 모든 계약·납품요구·라인 번호는 [JSON](root-retail-pack-and-large-scope-20261017.json)에 보존했다. 제설제 Z-1000은 bulk 에이전트가 원규격과 판매처를 보강했으므로 그 보고서를 연결하고 같은 가격 검색은 반복하지 않았다.

ILT-4 원 HWP 2,490,368바이트를 실제 내려받아 읽었다. SHA256은 `6179186f91cd61fc4f0334e19fc9b60ccb070c58b46097e8604edf52e06a851e`다. 아스팔트·물·유화제·부착방지제 완제품이며 택코트 연화점 55℃ 이상과 타이어 부착률 10% 이하를 규정한다. [NEP 인증기관 원문](https://www.nepmark.or.kr/sub4/pop_prod_intro.asp?i=7535)도 이 모델의 부착 저감 기능을 별도로 설명한다. 저렴한 일반 유제나 보수용 아스콘을 같은 기능으로 처리하지 않았다.

항공유는 공식 snapshot의 JP-8과 리터 단위, S-OIL 등재의 공장상차도를 확인했다. 원문 EGG 파일도 받았으나 현재 압축 도구가 형식을 지원하지 않아 내부 규격을 읽었다고 표시하지 않는다. 공급사 JP-8 상세는 HTTP 403으로 읽지 못했으며, 검색 단서나 다른 군의 낙찰가를 일반 민수 가격으로 바꾸지 않았다.

[다나와의 참치 6개 묶음](https://prod.danawa.com/info/?pcode=72747212)에서 낮은 가격이 발견돼 실제 판매처로 이동했다. G마켓 경로는 봇 확인 화면이라 중단했다. 다른 판매처를 읽은 [롯데ON 실제 상세](https://www.lotteon.com/p/product/LO2563570293?sitmNo=LO2563570293_2563570294)는 ‘동원 참치 1.88kg’, 판매가 25,580원, 온누리 혜택가 23,710원, 선택 수량 총 1개로 표시된다. 배송비는 3,500원이며 30만 원 이상 무료다.

롯데 상세의 필수정보를 펼치고 본문 iframe·연결 이미지 3개까지 읽었다. 캔은 1,880g·가다랑어 74.5%이나 6캔 세트라는 근거는 없다. 선택 수량 1개나 한 장의 캔 사진만으로 모든 포장 수량을 판정한 것은 아니며, 확인되지 않은 6캔으로 가격을 나누지 않았다는 의미다. 온누리 혜택가도 일반가로 쓰지 않았다. 이 경로의 비교 단가와 예상액은 미채택 상태다.

VIMS03은 신규 상태와 상세만 재확인하고 기존 운동복 조사 근거를 재사용했다. 기존 10.95억 원 시나리오를 새로 검증된 성능 우위나 접수액으로 승격하지 않았다. 다음으로는 완성 가드레일과 하드웨어 방화벽의 실제 일반 판매 경로를 분담 조사한다.
