## 가장 구체적인 레코더 후보

원품은 **26129504 / 시큐인포 Sentry 7816V5 / 실제 녹화 HDD 14TB**다. 공식 fact의 수량은 61대, VAT 포함 비교 금액은 297,070,000원, 대당 금액은 4,870,000원이다. 관련 번호는 계약 `002080079_1`, 납품요구 `R26TB02175357`, 라인 `2`다.

첨부 HWP에서 AHD 16채널 캡처보드, 녹화용 HDD 4TB 두 개와 6TB 한 개, 현장 설치도, 1년 무상 AS와 영업시간 기준 24시간 이내 출장 AS를 확인했다. 공식 속성의 FHD 480fps는 16채널당 30fps에 해당한다. IP 전용 NVR의 낮은 가격을 이 제품의 대체가로 사용하지 않는다.

제조사의 [iDS-7216HUHI-M2/XT 데이터시트](https://assets.hikvision.com/prd/public/all/doc/m000154746/Datasheet-of-iDS-7216HUHI-M2_XT_V4.83.100_20240311.pdf)는 AHD 입력과 FHD 30fps 녹화, 16채널 동시 재생, H.265 Pro+, HDD 두 개 지원을 명시한다. 입력 프레임률과 실제 녹화 프레임률을 따로 읽었다. 저렴한 HQHI 및 일부 다른 Dahua 모델의 FHD 15fps 사양을 섞지 않는다.

HDD는 DVR에 딸린 추가 구성 목록만 본 것이 아니다. **HDD 단품 페이지에서도 6TB와 8TB를 각각 선택해 1,087,200원 합계를 확인했다.** 카드·회원·쿠폰 혜택은 적용하지 않았다. 카페24의 판매가/VAT 설명은 보조 해석 자료이며 판매자 자체의 누락된 세금 안내를 확인한 것으로 표시하지 않았다.

설치·VAT 등의 미확정 조건을 모두 제외한 산술은 `297070000 − 1485400 × 61 = 206460600`원이다. **약 2.0646억 원은 검증된 절감액이나 심사 인정액이 아니다.** 2억 원을 유지할 수 있는 추가 비용 여유는 대당 약 105,911원뿐이다. 미확정 설치비를 0원으로 만들거나, 출장을 포함한 원계약 전체와 동일하다고 주장하지 않았다. 따라서 채택 비교단가와 채택 절감액은 `null`로 남겼다.

같은 씨넥스존 판매처에서 DVR 본체 564,400원과 14TB HDD를 모두 사면 부품 합계만 1,651,600원이다. 이를 적용한 조건부 산술은 196,322,400원으로 설치 등을 넣기 전에도 2억 원에 못 미친다.

다른 실제 판매처도 확인했다. 컴퓨존의 iDS-7216HUHI-M2/S는 352,410원 표시와 별개로 품절·입고 미정이라 제외했다. 컴퓨존의 XVR5216AN-4KL은 별도 모델이며 H.264+ 제품이다. 검색에 저장된 Seagate 추가 옵션 가격을 현재 가격으로 확정하지 않았고, 실제 DOM의 WD 옵션과 다시 대조했다. 반품·재조립·AS 교환 제품 또는 회원 전용 가격도 신규 일반가로 채택하지 않았다.

## 병렬 조사와 다음 확인

기존 native 서브 에이전트 세 개는 실제 조회 결과 사용량 제한 오류 상태다. 실행 중인 것처럼 보고하지 않았다. 별도로 Parallel `pro` 다섯 작업을 완료했으며 마지막 작업은 원품 정보를 상세히 넣어 Sentry 한 건만 다시 좁혔다. 자동 보고서의 분야 혼동, 원품 정보 미제공이라는 불필요한 문구, 건당 2억 원을 대당 200만원으로 잘못 읽은 계산은 연구자의 결론으로 채택하지 않았다.

마지막 Parallel 작업이 찾은 1CCTV의 WD84PURZ 8TB 365,000원은 원문을 추가 조회해 **구매 불가** 표시를 확인했다. 따라서 두 개를 사서 16TB로 만든다는 낮은 가격 계산을 폐기했다. HTTPS는 인증서 오류였고 우회하지 않았으며, 제공된 공개 HTTP 주소의 실제 GET 200 본문에서 판매 불가 상태를 읽었다. 정확한 Dahua I3 모델의 제조사 PDF에서는 전 채널 FHD 25/30fps 녹화를 별도로 확인했다. IVS·FACE를 켜면 동시 재생 채널이 16에서 9로 줄어드는 차이도 남겼다.

Jev는 실제 다음 동작 판단과 제한된 읽기 루프에 사용했다. 처음 두 실행 오류는 따로 기록했다. 추가 읽기 루프는 8회 판단 중 7회 스크롤을 실행하고 1회 stale page를 새로 관측한 뒤 `step_limit`으로 끝났으므로 DONE으로 세지 않았다. root가 직렬 Browser Harness로 실제 옵션과 합계를 대조했다. 판매 페이지의 DONE이나 공식 preview 통과를 기술 적합성 판정으로 읽지 않는다.

다음 작업은 Sentry의 **14TB 이상 장착 완성품 일반 판매가·VAT·실제 설치 범위**를 닫는 것이다. 엠스톤 대안은 최대 입력 채널만 늘어난 제품을 개선품으로 선언하지 않고 동시 재생·포함 저장장치·실제 필요한 기능 차이를 이어 확인한다. 보도블록은 원모델 일반 판매가 또는 문양·반사·투수·강도 조건과 개선 근거를 갖춘 구체 모델을 계속 찾는다.
