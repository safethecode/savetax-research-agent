# Pass 11: 표준 완제품·소모품 판매 원문

신규 7종을 공식 lookup으로 확인했고 모두 available이었다. 새 Parallel 쿼리 7개와 제조사·판매 원문을 읽었지만 채택 가능한 양수 근거는 아직 없다. 채택 단가와 검증 절감액은 모두 `null`, POST는 0건이다.

- **24264511 에토10유제**: 모든방역마트에서 실제 `500mL 20개` 옵션을 선택해 수량 1·상품 행 431,900원·최종 TOTAL 426,900원·BUY 표시를 확인했다. 쿠폰은 적용하지 않았다. 배송·추가 세금을 더하기 전 1L 환산가도 42,690원이다. 원품은 1L/통이며 새 공식 65 facts의 단가는 모두 37,000원이었다. 따라서 이 판매처는 양수 후보가 아니다. 모든 계약·납품요구·라인 번호와 공식 C 441,521,000원/Q 11,933을 JSON에 보존했다.
- **24756274 A-PLUS CWN060**: 실제 제조사 동양정수산업 페이지를 읽었다. 자동 컵 세척기 하위 페이지는 현재 업데이트 준비 중이다. 잘못 검색된 동양산업의 정수기나 A-PLUS CW06 인증명을 같은 완제품으로 확정하지 않았다. 기존 공식 96 facts·130대·743,600,000원과 전체 번호를 재사용했으며 새 GET으로 세지 않았다.
- **25660942 ECOTUM-100A**: 돌핀 제조사가 원챔버·404×471×1419mm·80개/시간과 물품번호를 직접 연결한다. 실제 구매방법의 같은 모델 스마트스토어 링크도 확보했다. 그러나 해당 판매 상세는 HTTP 429, 본인 실제 Jev는 오류 화면에서 BLOCKED였다. 현재 판매가와 구매 가능 상태는 미확인이다.
- **25199283 알루엔캡 60스트립**: 실제 60매/봉 판매 상세는 매장문의다. 다른 24매/봉 30,000원을 같은 포장 가격으로 쓰거나 적립금에서 가격을 역산하지 않았다. 상단 착불과 공통 배송비 4,000원도 확정 운임으로 합치지 않았다.
- **23604242 MA-S1050DP**: 제조사 실제 원문에서 모델·식별번호·1050L/day·자동배수·스테인리스·방부식 코팅을 확인했다. 다른 NED-S1085P의 실제 일반 판매 상세는 16,792,000원이지만 동일품이나 우수 대체품으로 확정하지 않았다. 9,810원 호스 가격을 완제품에 대입하지 않았다. 브라우저 클릭 실패와 공개 HTTP 경로 읽기를 구별했다.
- **24023732 AB1330A / 25192062 명랑시대 핫도그M**: 검색 단서 단계다. 동일한 새상품 완제품의 실제 판매 옵션·필수 비용을 읽지 못했으므로 가격이나 검증액을 채택하지 않았다. 가격비교 결과와 공공 문서를 일반 판매 근거로 바꾸지 않았다.

이번 묶음은 원품·일반 판매·접근 실패의 확인 범위를 보존한다. 새 공식 fact 65개와 기존 fact 96개의 전체 관련 번호, 원천 파일 해시, 옵션 전후 원문과 탭 정리 결과는 JSON 및 work에 있다. 이미 알려진 claimed 가전과 실제 조달보다 비싼 기존 경로는 반복하지 않았다.
