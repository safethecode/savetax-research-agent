# 내진 천장 비교 범위 정정 — 2026-10-17

사용자가 “필수 시험 성능이 필요해?”라고 질문해 공식 [대회 규칙](https://hackathon.savetax.now/docs/rules.md)을 다시 직접 GET해 전체 읽었다(HTTP 200). 규칙은 가격 근거·공식 fact·비교 단위·세금 기준 등을 요구하지만, 원품의 모든 납품 시험과 같은 시험성적서를 대체품에 제출하라는 의무는 명시하지 않는다. 접수 가능한 형식과 최종 심사의 사양 적합성 판단은 구별한다.

원품 HWPX의 “모든 사항 만족·전 항목 합격”은 원품 계약의 납품 검사 기준이다. 이를 다른 구조의 대체품 모두에게 그대로 적용하는 자동 탈락 기준으로 확장한 이전 해석은 과했다. 재사용 조사 스킬도 모든 보증·인증·미세 사양을 같게 만들라는 요구가 아니라고 명시한다.

후속 검토는 내진·불연이라는 핵심 목적과 시험된 실제 완성 구성, 비교 가능한 성능 우위, 공개 민수 취득가격을 중심으로 한다. 원품의 AC156 SDS 요구 최소1.50g와 젠픽스 지정 구성의 공개 AC156 SDS 약1.80g는 해당 지표의 대응 근거로 보존한다. 별도 2.5g 반복 진동 시험은 방식이 다르므로 이 숫자를 직접 비교하거나 미확인을 실패로 판정하지 않는다. 접합·처짐·재질·열저항 등의 차이와 미확인은 공개하며 원품의 모든 기능이 같거나 더 우수하다고 확대하지 않는다.

기존 약51.82억 원(5,181,791,227원) 차액은 DA-BAR·석고텍스·몰딩의 초기 조건부 산술이다. 젠픽스1.8g 성능을 이 다른 구성에 옮겨 붙이지 않는다. 젠픽스 가격은 실제 지정 구성에 맞춘 전체 BOM·세금·배송비를 아직 완성하지 못해 채택 단가와 예상액이 미확정이다. 시험 항목 차이 하나만으로 후보를 자동 폐기하지 않고 이 가격·구성 확인을 이어간다.

새 제출·preview·기존 접수 수정은 이 범위 정정에서 실행하지 않았다. 51.82억 원을 채택액에 더하지 않았다.
