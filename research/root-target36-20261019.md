# 남은 36회로 추가 131억 원 이상 목표

사용자가 기존 최대 13회 제한을 남은 약 36회로 정정했고, 추가 목표 13,144,391,772원 이상이며 초과해도 된다고 했다. 공식 계정 API도 누적 남은 횟수36회·오늘 남은50회로 확인했다. 건당2억 원 이상 후보를 포함하는 지시는 유지한다.

필요 평균은 **365,121,993.67원(약 3.6512억 원)**이다. 건당3.6억 원씩36건이면129.6억 원으로 184,391,772원 부족하다. 조사상 평균 목표를4억 원으로 두면36건144억 원, 목표 초과 여유는 1,255,608,228원이다. 이는 목표 산술이며 확보한 후보 금액이 아니다.

앞으로 접수한 검증 예상액을 목표에서 빼고 남은 공식 횟수로 다시 나눈다. 2억 원대 후보의 접수를 허용하되 현재 준비한 후보 합계와 고액 후보를 함께 본다. 반려 또는 수정이 생기면 별도 지시·권한 및 공식 상태를 따른다. 기존 접수의 본문·가격을 감사하거나 수정하지 않았다.

새 로컬 선별은 root0 담당46개와 다른 슬롯15개(차량 제외 전)다. 실제 신규 표적 조회는 root0 17개·타 슬롯11개이며, 기존 대기 후보4개를 별도 재조회했다. 합계32개의 상태는 {'claimed': 23, 'on_hold': 5, 'reform_found': 2, 'available': 2}다. 선별을 실제 판매가 검증 완료로 세지 않는다. 세 서브 에이전트의 기존 사용량 오류 상태를 재시도하지 않고 root가 임시 대조한 범위를 기록했다.

새 표적28개에는 즉시 등록 가능한 available이 없었다. 기존 대기 후보에서는 야전침대24077287과 리소 인쇄기23708443이 available이다. SL-M4040ND는 claimed, NT-381.B는 on_hold여서 신규 대상으로 접수하지 않았다. 두 available의 공식212개 fact·계약·납품요구·라인·단위·세금 기준을 JSON에 보존했다.

야전침대의 과거 preview 484,038,612원은 원품보다 더 나은 대체품이라는 검증을 뜻하지 않는다. [실제 판매 원문](https://theapplehouse.co.kr/product/detail.html?cate_no=125&display_group=1&product_no=6401)의 표시가65,000원·베이지 옵션·블랙 품절을 새로 읽었다. Jev 실제 실행은 SCROLL_DOWN 세 번 후 step_limit으로 끝났고 표시가를 관측했다. 이번에는 베이지를 선택한 뒤 합계를 다시 검증하지 않았다. 원품 정량 하중·중량이 없어 7075/150kg/2.7kg 판매 표기만으로 우위를 확정하지 않는다. 길이와 군용 용도 차이도 유지한다. 현재 채택액은 null이다.

리소 SF9250EIIAKj는 공식190개 fact·197대·1,070,498,000원이다. 전체에 같은 B를 적용했을 때 2억 원 차액 탐색 단가는 약4,418,771.57원/대 이하이며 실제 판매가가 아니다. [실제 제조사 옵션 원문](https://risokorea.co.kr/sub/option.php?cat_no=6&p_idx=83&pmode=view)은 잡 세퍼레이터와 스탠드를 기본 제공으로 명시한다. ADF도 원품 속성에 보존했다. 마스터 원지·잉크·임대 월금액·부속 없는 기본 모델이나 S2B 견적가를 완성품 판매가로 쓰지 않는다. 새 Parallel 검색은 부품이나 무관한 결과여서 채택할 일반 판매가를 확보하지 못했다.

**이번 preview·POST·기회 소모는0회, 새로 검증 완료한 접수 후보는0건이다.** 기준을36회·필요 평균약3.65억 원으로 바꾸고 과거 소액 대기열을 다시 연 것은 실제 조사 범위의 변경이다. 아직 추가131.44억 원을 확보했다고 보고하지 않는다.
