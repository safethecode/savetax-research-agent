### 24830440 Tibero 7 → SQL Server 2022 Enterprise

공식 상세에서 scorable fact 44개, 수량 722코어, 비교금액 11,047,322,000원(1코어당 15,301,000원, 부가세 포함)을 확인했다. 과거 다른 참가자의 반려로 on_hold였던 물품이며 현재는 available이다. 반려 사유는 알 수 없다.

판매 상세는 HTTP 200과 software 브라우저 세션으로 모두 읽었다. 상품명 `SQL Server 2022 Enterprise Core - 2 Core License Pack [CSP/영구]`, 모델 `DG7GMGF0FKZV:0001`, 판매가 ₩20,172,500, 세액 ₩2,017,250, 기업용 CSP 영구 사용권, 최소 구매 2코어, 배송비 무료, `바로 구매` 버튼이 보였다. 품절 문구는 화면에 없었다. 세액 표시의 기준이 불분명해 보수적으로 부가세 별도로 보고 10%를 더했다. 1코어당 비교 단가는 11,094,875원이며 원품 단가와의 비율은 약 1.379배다.

[Microsoft 라이선스 안내](https://www.microsoft.com/licensing/guidance/SQL)에 따라 물리 프로세서당 최소 4코어를 적용했다. 1~3코어와 홀수 코어 fact는 필요한 2코어 팩 수로 올려 fact별 단가를 넣었다. 1·2코어 fact는 절감액이 없어 본문에서 빠지고 28개 라인만 남는다. 가상머신 단위 사용권에는 SA나 구독이 필요하므로, 이 비교는 물리 서버 코어 수가 fact 수량과 같다는 가정이다.

사양은 [SQL Server 2022 에디션 문서](https://learn.microsoft.com/ko-kr/sql/sql-server/editions-and-components-of-sql-server-2022?view=sql-server-ver16)와 [Tibero 제조사 페이지](https://www.tibero.com/ko/products/Tibero)로 대조했다. Enterprise는 단일 인스턴스 컴퓨팅·버퍼 풀이 운영체제 최대이고, Always On 가용성 그룹·최대 16노드 장애조치 클러스터·TDE·Always Encrypted·파티셔닝·압축을 포함한다. Tibero의 Active-Active TAC는 조달 목록에 별도 물품(24830439 Tibero Active Cluster)으로 등재되어 있다.

[원품 계약 페이지](https://shop.g2b.go.kr/link/GMSF001_01/?ctrtItemMngNo=002461246_1040000010)의 규격서 ZIP(21,919,550바이트, SHA-256 `6ab06a26…05c7`)을 software 세션에서 내려받았다. 안의 Tibero7 스캔 PDF 13쪽(SHA-256 `3c0f94e2…69b3`) 중 1~4쪽과 12~13쪽을 그림으로 직접 읽었다. 확인한 내용은 다음과 같다.

- 1.1·1.3: TAC(장애 시 Fail-over 클러스터)는 Enterprise 도입 뒤 같은 코어 수만큼 추가로 사는 별도 물품 24830439다.

- 3.1: 지원 운영체제는 Windows·Linux·HP-UX·AIX·Solaris 계열이다.

이 내용을 본문의 사양 대응과 차이에 반영했다. 공공조달 문서는 원품 규격 확인에만 썼고 가격 근거로 쓰지 않았다. 갱신한 본문의 preview 금액은 같은 2,862,417,244원이었고, 가격 차이 검사는 1.36배로 통과했다. 이미 접수된 건이므로 갱신본을 revision으로 쓸지는 root가 판단한다.

남은 위험은 다음과 같다.

- Tibero의 Oracle 문법 호환과 UNIX 지원이 SQL Server에는 없어 이관 비용이 생길 수 있다. 본문 차이 항목에 적었다.

- 같은 판매처의 SQL Server 2025 Enterprise 상품은 다른 쇼핑몰(softinfo)에서 2,119,000원으로 표시되지만, 같은 몰의 Standard 2코어(5,579,000원)보다 싸므로 표기 오류로 보고 사용하지 않았다.
- 다나와 미링크 판매 목록의 `SQLServer Enterprise 2Core 2025 CSP 라이선스 22,400,000원 무료배송`은 보조 관측이며, 오픈마켓 경유라 근거 링크로 쓰지 않았다.

## 탐색 범위

`work/data/latest-20261017/full-catalog-priority.parquet`에서 세부품명에 `소프트웨어`가 들어간 로컬 금액 15억 원 이상 85개를 뽑아 공식 lookup을 1회 했다. available 65개, claimed 17개, claimed_by_me 2개, reform_found 1개였다. 이 중 원화 공개 판매가가 있는 상용 대체품이 존재하는 품목을 우선 검토했다. Parallel 검색은 30회 이상 실행했고, 검색 결과는 `work/software-goal1000/ps-*.json`에 있다.

공공조달 가격(나라장터·S2B·혁신장터·디지털서비스몰)은 판매 근거로 쓰지 않았다. 개인 지침과 키는 읽거나 출력하지 않았고 공식 API는 `SaveTaxClient`로만 호출했다.

## root 후속 지시 반영

- 24830440 Tibero는 root가 접수했다(2,862,417,244원). 23454737은 root, 23235820 VURIX는 다른 병렬 세션이 접수했다.
- Microsoft GA/SA·한컴·이스트소프트 품목은 industrial 담당으로 넘겼다. 이 에이전트는 알약 5.1의 국내 판매가 비교(ESET 25,000원 이상)만 기록했고 패킷은 만들지 않았다.
- 동일 제품을 우선하고, 대체품은 핵심 사양이 분명히 더 나은 경우에만 준비한다. 이 기준을 적용하자 남은 담당(Adobe, eXperDB, JEUS, WebtoB, TAC, 영상분석, 보안 SI)에서 추가 패킷이 나오지 않았다.
- 25796435 WebtoB 6 Standard(667코어, 약 11.3억 원)와 25830570 JEUS 21 Standard(449코어, 약 11.9억 원)는 10억 원 절감에 1코어당 각각 약 20만·41만 원 이하가 필요하다. 원화로 공개 판매되는 동일 제품이나 더 나은 대체품이 없다.
