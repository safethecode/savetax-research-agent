SYS-ACP-4F(24267330)는 공식 26개 fact·26개 납품요구, 28,957㎡, 비교 순금액 5,840,049,907원이다. 제목의 4mm는 알루미늄 복합 표면판이고 완성 두께는 30mm다. 원규격의 ACP별 BOM을 읽어 A6063 Z바·하부 프레임 4m·리벳 16개·STS304 와이어·부틸시트를 확인했다. 두 등재는 각각 납품장소차상도와 현장설치도이므로 모든 납품을 원판 취득으로 바꾸지 않는다. 같은 첨부명·크기의 기존 원문을 재사용한 사실과 새 다운로드를 구별했다.

[엔투아이의 Leisvill 4T](https://www.n2i.co.kr/category/jajae/priceon/priceView.asp?pid=P0000082)는 실제 일반 표시가 24,000원/㎡·최소 100㎡다. VAT 미확인·배송 협의이고 완성 레일·프레임·와이어 등이 없는 판재다. PE 심재가 원품 Mg(OH)2 포함 심재보다 우수하다는 근거도 없다. 이 가격을 완성 내진 패널의 단가로 채택하지 않았다. 실제 Jev 230ms의 스크롤 예측과 별도로 본문을 읽었으며 예측을 검증 완료로 표시하지 않는다.

STW-GP-10125 후속에서는 [SBPanel 제조사 원문](https://sbptcorp.com/)을 읽었다. 제조사의 RP1000·유리면 48/64K 사양은 확인되지만, 실제 Bidnbee 판매 SKU의 제조사라는 연결은 없다. 같은 명칭만으로 이 시험·인정을 판매품에 옮기지 않았다. 기존 판매처 성적서 이미지의 공개 아카이브 조회는 HTTP 503으로 실패해, 성적서를 복구했다고 기록하지 않는다. 기존 조건부 차액은 채택액으로 올리지 않는다.

[스틸네트워크의 2016-08-17 판매 안내](https://steel.or.kr/51/?bmode=view&idx=8035)를 실제 HTTP 200으로 읽었다. 국산 SD500·13mm 칸은 535, VAT 별도·도착 후 현금·1번들 1톤·25톤 단위 국산 전국 도착도다. 회사 소개는 실제 철강 유통업을 설명하며, 공공조달·뉴스 가격이 아니다. 다만 구형 글의 535에 원/kg라는 단위가 직접 적혀 있지는 않다. [같은 판매처 현행 안내](https://www.steel.or.kr/130)의 ‘Kg당 단가(원)’와 현재 915를 구별해 보존하고, 과거 535를 현재 판매가로 표시하지 않았다. 과거 실제 판매 안내라는 점 자체는 배제 사유가 아니다.

한국특강 KS-400-13(25218051)의 최신 공식 1,278개 fact는 17,148톤·14,056,078,716원이다. 모든 계약·납품요구·라인 번호를 JSON에 담았다.535를 원/kg로 읽을 때 VAT 포함 588,500원/t라는 값은 아직 조건부다. 실제 제강사·길이·적용KS판본과25톤 조건을 맞춰야 하며, fact마다 필요한 구매량을 계산한다. SD500의 강도 개선과 연신율·굽힘 차이를 함께 기록하고 모든 물성이 더 좋다고 주장하지 않는다.

追加 독립 검산에서 과거 표시 535/530을 원/kg로 해석한다는 가정에 VAT 10%와 fact별 25톤 배수 구매를 적용했다. 비교 단가를 소수 6자리에서 올리고 행별 차액을 내림한 조건부 합계는 KS-400-13의 178개 fact에서1,714,776,941원, KS-400-16의 125개 fact에서1,209,912,575원이다. 두 경우 가중 1.2배 기준은 수학적으로 충족하지만 판매품의 단위·제강사·길이 확인을 대신하지 않는다. 선택 행의 번호·구매량·올림 단가·내림 차액을 JSON에 보존했으며 실제 판매가·공식 미리보기·접수 예상액으로 채택하지 않았다.

판매처의 포장 중량표도 실제로 읽었다. 8m 열을 강조하지만, 1톤 포장 호칭과 실제 이론중량은 다르다. D13의 120본은 955.2kg, D16의 75본은 936kg이므로 번들 호칭을 정확한 1,000kg로 바꾸지 않는다. 위 25톤 조건부 구매량은 실제 번들 개수까지 확인한 비용이 아니다.
