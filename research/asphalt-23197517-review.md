# 유화아스팔트 고액 후보 검토

ILT-4는 공식 545개 납품 사실의 13086드럼, 7,067,835,016원 후보다. 비교 단가와 절감액은 아직 확정하지 않았으며 제출하지 않았다.

국내 RSC-4·FRS COAT 200L 상품을 찾았지만, 쿠팡은 Access Denied, G마켓은 봇 확인 화면이라 현재 브라우저 판매가를 읽지 못했다. 검색 가격이나 쿠폰가를 실측 일반가로 사용하지 않았다. 성천기업의 35만 원 RSC-4에는 품절 표시가 있었다.

원품은 타이어 부착저감용 개질 제품이다. 일반 택코트 유제와 동일 제품으로 부르지 않으며, 200L와 원품 200kg의 포장 대응도 검토해야 한다. 제조사 GobizKorea의 RSC-4 1드럼 200kg 표기는 보조 자료로만 보존했다.

전체 계약·납품요구·라인 번호는 JSON references에 있다. 다음 단계는 읽을 수 있는 국내 판매처의 실제 제조사·포장·가격과 원품 기능 차이 확인이다.
