# 콘크리트 호안·옹벽블록의 동일 모델 경로 확인 — pass16

신규 채택 단가와 검증 절감액은 확보하지 못했다. 상위 로컬 220종의 기존 기록을 먼저 확인하고, 기존 고정본과 접수는 유지했다. 콘크리트 두 분류의 기존 7,521종 순위에는 총납품 50억 원 이상 품목이 없었다. 이 수치는 전체 웹 실독 수가 아니다.

표적 6종을 새 조회해 4종은 available, SW-024와 TS-750은 claimed였다. available 4종의 공식 fact 193개는 절단 없이 계약·납품요구·라인 번호와 Q·C·단위·세금 기준을 JSON에 모두 보존했다.

[우리콘크리트의 실제 생태견치블록 상세](https://wrcon.co.kr/page/product03_2.php)는 물품번호 **22138834**, 500×500×250mm, **8개/㎡**를 명시한다. 독립 bulk 브라우저의 실제 텍스트에서도 같은 표를 읽었다. 전면적 기준이므로 500×500mm를 곱해 4개/㎡로 바꾸면 안 된다. 공식 REST의 75kg/개를 함께 쓰면 계산상 600kg/㎡이지만, 이는 조사자의 단위 계산이며 구조 시험이나 판매가가 아니다.

제조사 페이지는 하천 사면 보호·식생옹벽 용도와 결합돌기·결합홈을 설명하고 제품 문의 링크를 제공한다. 공개 판매 가격·VAT·팔레트·운임은 확인되지 않았다. 제품 문의나 연락은 하지 않았다. 제조사 표는 회색·적색에 같은 물품번호를 쓰므로 특정 색상의 별도 판매 SKU까지 확정하지 않았다. 공식 압축강도 28N/㎟ 이상은 REST 속성으로 구분했다.

토지 TJPB250-1, 다성기업 NB-G200, 일신콘크리트 IS-250은 정확 모델과 제조사명으로 검색했으나 같은 모델의 신품 일반 판매 상세를 확보하지 못했다. 반환된 다른 제조사 제품, 속빈 건축용 블록, 여행용 수납용품, 표준품셈은 비교가격에서 제외했다. 개·㎡·m³ 사이의 단가를 임의로 환산하지 않았다.

Parallel 실제 호출 7건, 웹 검색 질의 4개, HTTP HTML 3페이지·메뉴 JavaScript 1개, Jev 1회, 독립 브라우저 읽기 1회를 구분한다. Jev는 제품 목록에서 BLOCKED·178ms를 예측했지만 이후 상세 페이지의 실제 브라우저 읽기는 성공했다. Jev 예측을 접근 실패나 가격 검증으로 바꾸지 않는다. 공개 가격 검증 0건, preview·POST 0회다.

이번 결론은 읽은 경로에서 일반 판매가를 확보하지 못했다는 뜻이다. 시장 전체에 더 싼 상품이 없다는 결론은 아니다. 기존 케이토목·건자재 가격표와 기한 전 hold는 재조회하지 않았다. SW-024와 TS-750은 과거 원장의 상태가 충돌해 이번 1회 표적 조회에 포함됐고 claimed 확인 후 후속 조회·검색을 중단했다. 나머지, 원천 시각·URL·SHA256 및 전체 공식 번호는 JSON에 보존했다.
