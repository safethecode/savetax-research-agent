# 산업 분야 1,000억 원 목표 후속 조사

현재 새 제출 준비 후보는 0건이며, 이번 조사에서 preview나 점수 제출을 실행하지 않았다. 채택 예상액도 0원이다. 사용자 보고치인 현재 110억 원과 남은 50회를 기준으로, 추가 890억 원을 채우려면 남은 제출의 평균 예상액은 **17.8억 원**이어야 한다. 신규 제출 최소액은 최신 지시인 10억 원을 따른다.

## 지정 도구·공식 자료 복원 후 진행

초기 누락됐던 `.env`, 개인 지침과 전체 데이터셋이 복원됐고, 부모가 Mac 브라우저 경로를 수정했다. 이후 실제 **Parallel 검색 15회**, 독립 `industrial` 세션의 **Jev-ultrafast 예측 1회**와 Browser Harness 읽기에 성공했다. Jev의 217ms·`CLICK` 예측은 가격 검증 완료나 자동 실행 결과가 아니다. 조사한 실제 브라우저 원문을 별도로 검토했다.

복원된 전체 Parquet에서 무정전·예취기·예초기·전원공급·발전기·축전지를 선별하고 `dlv_key` 중복을 제거했다. 로컬 납품금액 10억 원 이상은 MARCHEⅡ 500, BLUPS-R3400-N-30MSBS, Orec SRM981의 3종뿐이었다. 최신 lookup에서 MARCHEⅡ 500은 `claimed`, 나머지 2종은 `available`이었다. 400kVA·30분 UPS의 본체와 축전지 전체 가격이나 승용 예취기의 신품 가격을 작은 UPS·배터리 한 개·부품 가격으로 대신하지 않았다.

산업·생활 완제품은 기존 담당 `owner_slot=3`, `md5_batch>=200`, 로컬 납품금액 10억 원 이상으로 확장했다. 65개를 최신 lookup했고 29개가 `available`이다. 이 수는 사양·실제 판매가 검증 완료 수가 아니다. 새 공식 상세 7개에는 344개 scorable fact가 있으며, 계약번호·납품요구번호·라인 번호·비교 기준 전체를 동명 JSON의 `current_official_fact_records`에 보존했다.

### 타스만 26093067: 큰 잠재액, 우수성 검토 진행

타스만은 과거 보류에서 현재 `available`로 바뀌었다. 공식 C는 **16,594,600,000원**, Q는 **397대**, scorable fact는 **105개**, 고유 납품요구는 **14건**이다. 397대를 105건이나 14대로 바꾸어 세지 않는다. 대체품의 실제 구성 단가가 내려가면 큰 예상액이 가능하지만, 지금 채택액은 0원이다.

[공식 상품](https://shop.g2b.go.kr/link/GMSF001_01/?ctrtItemMngNo=0024B0245_1100000248)의 실제 DOM에서 `규격서.zip`을 눌러 422,803바이트를 내려받았다. 원본 SHA256은 `1172fa7b95b504215599178af8da91acad51eafed0ee6b4cee24a65f5f7eb070`이다. 매크로는 실행하지 않았다. 읽기 전용으로 spreadsheets 스킬을 적용해 `규격서_화물트럭_26MY.xlsx`의 물품번호 26093067과 행·열 대응을 확인했다.

원규격은 화물운송용 4WD 자동 픽업 본체다. G2B 제목에는 군용 타스만이 표시되며, 캐노피·특수위장도장·하드탑 등 패키지는 별도 동시구매 옵션이다. 이를 본체 4,180만원에 포함된 것으로 확대하지 않는다. XLSX는 2,151cc·210마력·전장 5,410mm·적재함 1,512×1,572×540mm·축거 3,270mm·복합연비 9.8km/L를 표시한다. 최대토크 셀 G191은 **확인필요**라고 적혀 있다. 공식 원시 API의 441Nm 값을 XLSX에서 읽은 값처럼 표시하지 않는다. 같은 ZIP의 2025년 가솔린 규격표도 이 디젤 모델과 섞지 않는다.

[KGM 공식 무쏘](https://www.kg-mobility.com/pr/model/show-room/200000100030004)와 [제조사 시승 안내](https://www.kg-mobility.com/br/news/notification/0000001363)를 대조하고 있다. **217마력은 가솔린**이며, 디젤은 202마력이므로 타스만 210마력보다 높은 것으로 쓸 수 없다. 롱데크·리프 스프링의 700kg 적재량과 지상고 개선 가능성, 출력·견인능력 감소 및 편의 옵션을 함께 검토한다. 일반 판매가·VAT·선택 구성과 우수성이 확정되기 전에는 제출하지 않는다.

### SRD-Ai02: 용도 오인을 정정

공식 REST의 PE 탱크 20,000L·PE 배관·100m 구간·380V·11kW를 확인한 뒤, 초기의 차량 지붕 제설장비 가설을 폐기했다. [리텍 자동염수분사장치](https://www.retech.kr/sub020101/view/id/42)의 원격제어·환경센서·5,000L 탱크(변경 가능)·40A 배관을 독립 브라우저에서 읽었다. 실제 공개 판매가격이 없고 저장 용량도 다르므로 비교 단가를 채택하지 않았다.

공개 manifest는 인증 없이 직접 GET해 HTTP 200과 버전 `a2edc57482d9cee1f04e`를 확인했다. 별도 폴러는 만들지 않았다. 초기 인증 없는 표적 API 요청의 HTTP 401은 복원 전 기록이며, 복원 뒤에는 기존 `SaveTaxClient`의 공식 HTTPS Authorization 경로만 사용한다.

다음에는 현재 available인 타스만과 군용 레이어링 방한복 26316987·26316991의 원규격·완제품 범위와 더 우수한 실제 대체품을 이어 검토한다. UPS·예취기의 전 분야 고액 선별 결과는 보존하고 같은 저액 제품 검색을 반복하지 않는다. 검증된 신규 예상액 10억 원 이상만 root의 preview 대기열로 넘긴다.
