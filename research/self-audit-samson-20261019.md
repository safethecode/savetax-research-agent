# 삼손 제출 자체 감사

2026-10-19 재검토. 활성 61건의 현재 예상액은 **32,665,270,883원(326.65억 원)**이다. 기존 반려 1건을 포함한 전체 62건의 현행 차수와 공개 반증 203개를 확인했다. 활성 61건·4,752개 라인의 공식 C/Q/B 차액 계산은 모두 일치했다.

하드디스크와 차량은 기존 제외 지시에 따라 상태·반증·산술만 확인했다. 나머지 활성 59건은 기존 원문 조사와 현재 판매·제조사 자료를 대조했다. 이 문서는 대회 심사 판정이 아니다.

|---|---:|---:|

**위 금액은 감액 확정액이나 확률을 반영한 예상 손실액이 아니다.** 확인된 사양 차이·실제 누락 비용이 있는 제출과 추가 증명이 필요한 제출을 구별한 합계다. 실제 추가비용·적합 완성가격을 확인하지 못한 건은 감액을 숫자로 만들지 않았다.

## 큰 쟁점

- 방화벽 6건: 7,511,070,000원. EFG 포트 수, UDM의 보안 인터페이스 구조, 로그 저장·국내 구축/유지 조건의 차이가 남는다. NAT·IPsec·일체형 HW가 없다는 식의 반증은 제조사 원문으로 일부 반박 가능하다.
- VURIX: 4,931,899,814원. WAVE의 채널 라이선스는 VURIX 서버의 활성화 키가 아니며 원품에 포함된 국내 현장 지원·시스템 전환 비용이 반영되지 않았다. 4채널 팩의 잔여 수량 비용은 이미 포함돼 있다.
- Tibero: 2,862,417,244원. SQL Server 기업용 영구 라이선스 자체는 실제 판매 상품이며 코어 팩 올림·세액도 반영됐다. UNIX·Oracle 호환 환경과 이관/설치 범위는 다르다.
- 단열재·중소 옹벽블록 3건: 2,346,840,169원. 압축잔류변형·사용온도 또는 압축강도에서 원품보다 불리한 공개 사양이 확인된다.
- 패널 4건: 2,950,777,120원. 개별 용달 착불 운임은 실제 판매 조건이지만 B에는 금액이 없다. 250T는 기존 양수 라인을 유지할 경우 1.2배 기준까지 추가비용 여유가 약 300.21원/㎡다. 실제 운임을 확인하지 않고 기준 탈락이나 정확 감액을 확정하지 않는다.

## 이번 정정

Acrobat 비교 제출(25590567)은 제조사의 구매 안내 창에서 기업용과 조달용 모두 연간 55,000원(VAT 포함) 공시를 확인했다. 직전 차수의 기관용 공시 가격이 없다는 설명을 **revision 3**으로 바로잡고 공개 본문을 재조회해 일치함을 확인했다. 조달 공시 가격을 새 시중 가격 근거로 쓰지 않았고, 기존 일반 판매처·B·납품 라인·예상액은 유지했다. Acrobat 고급 기능과 해당 소매 사용권의 기관 적용 문제는 미해결이다.

하드디스크·차량 수정, 신규 점수 제출, 철회는 없었다. 신규 등록 잔여 한도는 36회다. 원문에 있는 값과 이전 조사에서 잘못 읽은 값을 구별했고, 일반 판매 가격이나 조건을 만들어 비교가격을 낮추지 않았다.
