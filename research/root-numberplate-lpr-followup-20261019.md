# 건물번호판·차량번호인식기 후속 조사

신규 접수와 검증 절감액은 0건이다. 두 품목의 공식 납품 사실 293개와 계약·납품요구·라인 번호 전체를 JSON에 보존했다. SaveTax 검색은 후보 발견에만 썼고 통계 추정가를 비교 가격으로 쓰지 않았다.

## 에스디티 AB-0009, 25461083

[공식 사실](https://hackathon.savetax.now/v1/events/current/items/25461083)은 235개 fact·217,720개·2,148,319,000원이다. 원품은 알루미늄 260×215×1mm 오각형이며 UV 인쇄·스티커 부착 방지·QR 기능을 포함한다. 현행 조달 등재가 7,000원과 10,000원을 시중 판매가로 쓰지 않았다.

Parallel에서 [제조사 홈페이지](https://www.xn--2z1b50xunccxt.com/)를 새로 찾고 실제 브라우저에서 직영 스마트스토어와 상품 연결을 읽었다. 스마트스토어는 실제 서비스 오류 화면이어서 판매가를 확인하지 못했다. 쿠팡도 Access Denied였다. 접근 실패를 성공이나 저가 근거로 바꾸지 않았다.

[아크릴마트 판매 원문](https://m.acrmart.com/product/%EB%8F%84%EB%A1%9C%EB%AA%85%EC%A3%BC%EC%86%8C%ED%8C%90-%EC%9E%90%EC%9C%A8%ED%98%95-%EA%B1%B4%EB%AC%BC%EB%B2%88%ED%98%B8%ED%8C%90/153574)은 18,000원 기본 표시가와 260×260·300×300·400×400mm 옵션을 실제 확인했다. 선택 합계나 원품 기능 대응은 검증하지 않았고, 표시가 자체도 원품보다 높다. 이 판매처를 절감 근거로 채택하지 않는다.

## 비젼아이티에스 VI-LPR100, 24159713

기존 자동 선별의 수량 결측 판정을 재검토했다. [공식 사실](https://hackathon.savetax.now/v1/events/current/items/24159713)은 58개 fact·128대/식·1,725,952,000원으로 Q가 실제 존재한다. 각 fact의 원래 단위·세금 기준·관련 번호를 그대로 보존했다.

[씨에이치파크 판매 원문](https://chpark123.cafe24.com/product/%EB%8B%A8%EB%8F%85%ED%98%95-%EC%B0%A8%EB%9F%89%EB%B2%88%ED%98%B8%EC%9D%B8%EC%8B%9D%EA%B8%B0/36/category/1/display/3/)에서 1개 합계 **3,190,000원**, 직접배송·무료 표시를 실제 읽었다. Jev는 한 번의 DONE으로 가격 표시에서 종료했으며, 별도 Native DOM과 상세 이미지도 대조했다. 도서산간 추가비 가능성은 표시된 범위대로 남겼고 VAT는 미확정이다.

[상세 이미지](https://chpark123.cafe24.com/web/upload/NNEditor/20260206/331226fff3b8fb22415a10f389b919b9.jpg)를 정상 브라우저에서 직접 읽어 실제 모델 **CHP-LPR-101**과 전광판·2MP 카메라를 확인했다. **인식 엔진은 별도**이며 설치 시공·시험 조정도 제품 금액에서 빠진다. 엔진 가격을 0원으로 두거나 별도 엔진 없이 차량번호 인식 기능이 완성됐다고 하지 않는다. 인식 성능과 기존 시스템 연결 대응도 미완료다. 제조사 VI-LPR100 홈페이지의 HTTPS 인증서 오류는 우회하지 않았다.

본체 가격만 대입하면 차이는 1,317,632,000원이지만, 필수 엔진·세금·실제 범위 차이가 미확정이므로 **채택 B와 검증 예상액은 null**이다. 제출 대기 합계에도 넣지 않았다.

[파킹세일의 다른 완제품](https://www.parkingsale.co.kr/goods_detail.php?goodsIdx=102112)은 실제 견적 문의 상품이었다. 10,000원은 견적 금액의 결제 입력 단위로, 본체 판매가가 아니다.

CHPark 상세 JPEG의 Python GET은 403이었지만 정상 브라우저 직접 이동에서는 두 이미지가 로딩됐다. 읽은 픽셀은 PNG 렌더로 보존했고 원래 JPEG 파일의 바이트 해시와 구별했다. 스크린샷 호출 한 번은 60초 제한으로 실패했다. 원시자료와 키는 커밋하지 않으며 공개 JSON에는 원천 해시와 판단만 보존한다.
