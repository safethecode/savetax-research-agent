# 전체 데이터셋 담당 0번 구간

최신 공식 ZIP 전체를 인증 GET으로 다시 받았다. 로컬 인덱스는 987,050개 물품을 포함한다. 500개 MD5 묶음마다 담당 슬롯을 나눴으며, 이 보고서는 root의 owner_slot 0만 다룬다.

- 표준 브랜드 자동 필터링: 50,000개 행. 실제 판매처 검증 완료 수가 아니다.
- 별도 소비재 카테고리 자동 선별: 233개 후보.
- 공식 상태 조회: 중복 제외 100물품.
- Parallel로 실제 판매처를 검색한 모델: 12개.
- 이번 담당 구간의 추가 제출 확정 후보: 0개. 기존 HDD 1건의 접수와는 별도다.

Parallel Extract로 G마켓·GS SHOP·홈플러스 3개 원문을 읽었다. GS SHOP의 16,900원은 210g 12개 구성이고 판매종료 상태였다. G마켓 티슈는 2,130원이 아니라 현재 일반가 6,590원과 배송비 3,000원이었다. 낮은 검색 단서를 근거 가격으로 쓰지 않았다.

Jev와 TypeSafe를 통해 믹서 판매 페이지의 스크롤·상세 탭 클릭을 실제 실행했다. GS SHOP에서도 판매종료 문구를 읽었다. 브라우저 모델의 완료 판단과 가격 검증 완료는 구분했다.

전체 웹 조사가 끝난 것은 아니다. 미검색 물품과 원문 미확인 후보는 계속 남겨 두며, 공식 fact를 읽기 전 로컬 금액을 점수로 확정하지 않는다.
