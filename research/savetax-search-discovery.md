# SaveTax 검색을 통한 추가 후보 발굴

사용자 지시에 따라 root가 검색의 추정 차액순4쪽을 직접 읽었다. 80개 등재번호를 공식 lookup으로 조회하니 on_hold62개·claimed11개·available7개였다. available은 물품번호로 합치면6개다. 실제 판매가 검증 완료6건을 뜻하지 않는다. SaveTax의 통계 가격은 제출 근거로 쓰지 않는다.

Parallel로 미라클 MS-125CR·LED 도로표지병 판매처·현도 리프트경광등·BLUEMAX5100의4개 쿼리를 실제 병렬 검색했다. 관련 없는 기업보고서나 일반 LED 조명도 반환되어 실제 상품과 구분했다. 조명코리아의 실제 표지병 상세까지 이어 읽었으나 태양광 자동 점등형으로 원품의PLC제어와 다르며 비교 단가를 채택하지 않았다.

Jev-ultrafast도 하이크비전67의 후속 모델 옵션, ITNCCTV20295의PTZ카메라, 조명코리아1766562078의백색 옵션을 대상으로 실제 호출했다. 각 결과는 다음 동작 예측이며 native의 판매 모델·가격·옵션 확인과 구분했다. 판독한 가격을 전체 사양 동등성이나 대회 승인으로 사용하지 않는다.

후보별 전체 계약·납품요구·라인 번호는 JSON에 보존했다. 기등록·등록 대기 품목을 새 접수하지 않았다.

추가로 데스크톱컴퓨터 검색의 납품총액순 20개를 공식 조회했다. available 9개·claimed 10개·on_hold 1개였으며, available의 실제 총액은 약 475만~6,350만원으로 작아 제출을 보류했다. 현도 리프트경광등의 실제 판매 상세도 읽었지만 가격문의·구매불가였으므로 판매 단가를 만들지 않았다.
