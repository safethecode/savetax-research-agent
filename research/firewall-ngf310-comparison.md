# BLUEMAX NGF 310과 UDM-Pro-Max의 방화벽·IPsec·기본 IPS 취득가격 비교

공식 납품 사실 123건, 수량 270, 비교금액 1,485,000,000원에 단가 1080000원을 적용해 예상액 1,193,400,000원이 접수됐다. [공개 접수](https://hackathon.savetax.now/#/submission/14da6e95-ab5f-4e66-bffe-1deb898f3940)

공식 납품 사실 123개, 고유 납품요구 122건의 270대·1,485,000,000원을 UDM-Pro-Max의 관부가세와 표시 배송비가 포함된 일반 판매가 1,080,000원과 대조했다. 예상 차액은 1,193,400,000원이다. 두 제품의 Stateful/L7 방화벽·NAT·IPsec 사이트 간 VPN·기본 IPS라는 공통 기능을 사용하는 장비 취득가격 비교다.

원품의 독립 보안 인터페이스 8개와 대체품의 내장 L2 스위치 포트 8개는 구조가 다르다. 별도 관리 포트·시리얼 콘솔, 포트별 독립 보안 처리와 기존 망 구성의 그대로 이전은 입증하지 않았다. 원품의 Throughput 8Gbps와 대체품의 IDS/IPS 5Gbps는 측정 항목·조건이 달라 같은 성능으로 비교하지 않았다. 원품 1TB 로그 저장장치와 대체품 eMMC 32GB·내장 SSD 128GB도 용도와 보존량이 다르다.

원품의 PQC·국산 암호·BLUEMAX NGF V3.0 CC 인증 구성, 가상 시스템·SSL 복호화·DLP/AV·단말 점검·SSL VPN FIDO/MFA·전용 관리 및 기존 터널 호환성까지 충족하는 교체품으로 주장하지 않는다. 원품 Active-Active HA와 UDM Shadow Mode도 다르며, 본 가격은 이중화 쌍이 아닌 1대 가격이다. 선택 유료 CyberSecure 구독은 포함하지 않았다.

원계약은 현장설치도·하자보수 1년이고 판매품은 국내 AS가 불가능한 해외구매대행이다. 설치·이전·유지보수 비용 차이는 금액에 반영하지 않았다. 표시 무료배송을 적용했으나 일반 초과중량·특대형 추가운임 안내가 있으며, 미국 영업일 기준 10~20일·유동 재고 조건이다. 전량 동시 공급이나 설치 완료 계약 전체의 실제 절감액을 확정하는 비교는 아니다. 대체품의 국내 KCMVP 적용은 확인하지 않았다.

서로 다른 제조사·모델의 일반 Stateful/L7 방화벽·NAT·IPsec 사이트 간 VPN·기본 IPS 장비 취득가격을 비교한다. 독립 보안 인터페이스의 망 구성·정격 처리량·로그 보존량, PQC·국산 암호·국내 인증·가상 시스템·SSL 복호화/DLP/AV·단말 점검·전용 관리·고급 VPN 인증·Active-Active HA의 동등성은 포함하지 않는다. 실제 기관의 트래픽과 보안 정책을 그대로 충족하는 교체품이라는 주장은 아니다. 1대당 관부가세 포함 1,080,000원과 표시 무료배송을 적용했고 유료 CyberSecure 구독, 설치·정책 이전·국내 유지보수 비용은 포함하지 않았다. 해외구매대행의 일반 추가운임 가능성·미국 영업일 10~20일·국내 AS 불가 조건을 공개한다.
