# 고유황 경유의 세전 가격과 실제 공급 범위 확인

물품 20282162는 2026-10-19 공식 관측에서 available이었다. 공식 5개 fact의 수량은 47,012,403L, 비교금액은 65,337,710,110원이다. **653.38억 원은 납품 비교금액이며 절감액이 아니다.** 모든 계약·납품요구·라인 번호와 공식 C·Q는 동반 JSON에 보존했다.

[실제 원품 상세](https://shop.g2b.go.kr/link/GMSF001_01/?ctrtItemMngNo=R26TA02076008020000001)의 201,183바이트 규격 ZIP을 내려받고 두 HWP 본문을 읽었다. 원품은 선박용 고유황 경유이며 수요기관 탱크주입도다. 본문은 지정 장소까지 납품·주유하는 범위를 설명한다. F76으로 추정하거나 자동차용 경유·등유·중유 가격을 대입하지 않는다. 해당 상세의 계약해지 표시와 공식 이벤트의 관측 available은 따로 보존했으며 품목 전체의 현재 계약 상태를 단정하지 않는다.

[해운조합 유가표](https://ns.haewoon.co.kr/site/main/oil2/list)의 웹 검색 발췌에서 열 제목까지 확인했다. 0.05% MGO 행의 1,215.61원은 세전 열이고 1,773원은 과세유 열이다. 직접 페이지 열람은 timeout 또는 TLS 호스트명 불일치로 실패했다. 발췌 가격을 실제 검증한 판매가로 표시하지 않았고, 세전 숫자만 골라 절감액을 만들지 않았다.

Parallel 실제 검색 세 건에서도 공공 입찰 단가, 자동차용 주유소 가격과 가격 인하 기사가 나왔으며 같은 품목의 낮은 일반 공급가는 확보하지 못했다. 비교가격과 채택 절감액은 null, 신규 preview·POST는 0회다. 이 원문과 접근 결과를 남겨 같은 잘못된 가격 경로를 반복하지 않는다.
