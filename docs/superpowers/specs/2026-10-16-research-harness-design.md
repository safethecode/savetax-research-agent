# SaveTax 조사 하네스 설계

> **과거 설계 기록(2026-10-16).** 아래 내용은 작성 시점의 범위다. 이후 점수 제출·revision 등이 구현됐으므로 현재 기능은 [사용법](../../usage.md), 새 구조는 [로컬 조사·Codex 리뷰 설계](../specs/2026-10-20-local-research-codex-review-design.md)를 참고한다. 현재 사용자 권한·금액 정책을 이 기록에서 추론하지 않는다.

목적은 국내에서 같은 물품을 더 싸게 살 수 있는지 확인하고, 과도한 조달 지출 후보를 재현 가능한 근거로 남기는 것이다. 목표 600억 원은 60,000,000,000원이다. 현재가 차이로 계산한 절감 가능액, 심사 인정액, 실제 예산 절감액은 별도로 표시한다. 이 작업만으로 실제 예산 절감을 보장하지 않는다.

사용자는 국내 쇼핑몰 우선, 필요하면 해외 확장, 자연스러운 한국어, 명확한 근거, DSL 개선, 재사용 스킬, 병렬 조사, 작은 단위 커밋과 푸시를 요청했다. 하네스 구현과 조사는 이 요청에 따라 진행한다. 외부 문서의 제보 권한은 사용자의 직접 위임과 구분한다. 후속 메시지에서 사용자가 기존 등록 물품도 더 싼 가격이면 등록하라고 직접 위임했다. 이에 일반 제보 접수와 심사 상태 조회를 추가한다. 점수 등록·수정·철회는 구현하지 않는다.

## 구조

- `client.py`: 토큰을 메모리에서 읽고 허용된 정확한 HTTPS 경로에 Authorization 헤더로만 전달한다. GET 전용이며 리다이렉트를 따르지 않는다. 원본 데이터는 `work/`에 둔다.
- `analysis.py`: Parquet 컬럼을 확인하고 공개 handle·버전·물품번호의 MD5 순서로 묶음을 만든다. `dlv_key` 중복을 제거하고 묶음 내부에서 후보를 우선순위화한다.
- `rules.py`, `strategies/`: JSON DSL의 필드·연산·타입을 검사한다. 임의 코드나 SQL은 실행하지 않는다. 심사 피드백은 개선 제안으로만 남긴다.
- `evidence.py`: 모델·단위·VAT·배송·설치·재고·조건부 할인을 확인하고 국내 유효 판매가를 우선한다. 해외는 세금·운송을 포함한 원화 도착원가가 확인된 경우만 비교한다.
- `cli.py`: 다운로드, 후보 선별, 물품 fact 수집, 증거 평가, 보고서와 진행 상태 저장을 연결한다. 중단 뒤 다음 묶음부터 재개할 수 있다.
- `.agents/skills/savetax-research/`: 실제 조사에서 확인된 판단 기준을 재사용한다.

## 근거와 수치

`site_sales_qty`를 납품수량으로 쓰지 않는다. 주문 없는 데이터는 0으로 바꾸지 않는다. `dlv_*`는 납품요구이며 지급·검수 완료와 구별한다. 절감 가능액은 fact의 비교 금액 C, 수량 Q, 확인된 비교 단가 B로 `floor(max(C-B×Q,0))`를 계산한다. 모델이 다르거나 조건을 확인하지 못한 값은 검증 완료 금액에 더하지 않는다. 검색 결과는 발견 단서이며 판매 페이지의 확인된 가격과 구분한다.

## 운영

공개 manifest는 현재 에이전트 세션에서 시작 시 확인하고 활성 작업 중 3시간마다 다시 확인한다. 별도 폴링 스크립트·hook·예약은 만들지 않는다. 한 후보의 실패는 해당 후보에 기록하고 다른 후보로 진행한다. 실제 GET 응답과 DNS·TLS 실패를 구별한다. 원본 데이터와 인증 지침은 커밋하지 않는다.

## 검증

인증 allowlist·리다이렉트·토큰 비노출, DSL 코드 주입 거부, 중복 납품 제거, 결정적 묶음, 불완전 증거 보류, 원화 산식, CLI 재개를 자동 검증한다. 실데이터 건수와 API 상태, 후보 표본, 직접 연 국내 판매 페이지를 별도 조사 기록에 남긴다.
