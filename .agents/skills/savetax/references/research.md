# 조사와 비교

## 자료 확보

조달 자료는 공식 REST·전체 데이터셋을 쓴다. SaveTax 검색 화면은 후보 발견에 사용할 수 있지만 사이트 추정가·분석 글은 판매가 근거가 아니다. 등재번호는 공식 lookup으로 물품번호에 매핑해 중복을 제거한다.

필요한 공식 문서는 인증 없이 확인한다: [manifest](https://hackathon.savetax.now/docs/agent-guidance-version.json), [data](https://hackathon.savetax.now/docs/data.md), [rules](https://hackathon.savetax.now/docs/rules.md). 진행 중 공식 작업은 세션 시작과 활성 3시간마다 manifest를 직접 확인한다. 로컬 문서 정리·저장 자료만의 검토를 위해 네트워크 점검을 시작하지 않는다. 폴러를 만들지 않는다.

사용자가 정한 금액 순서와 범위 안에서 검증 예상액이 큰 후보부터 처리한다. 고액이라는 이유만으로 적합성이 확인되지 않은 대체품을 통과시키지 않는다. 국내 판매처를 먼저 찾고 필요하면 해외로 넓힌다. Parallel·상품검색은 발견 도구이며 실제 판매처의 본문·옵션·구매 표시를 읽어 가격을 확정한다. 같은 가격표는 한 번 읽어 공유한다.

## 근거 한 건에 남길 내용

| 항목 | 확인 내용 |
|---|---|
| 출처 | 실제 상품·제조사 URL, 관측 시각, 원문 또는 화면과 해시 |
| 상품 | 실제 모델과 suffix, 핵심 사양, 신품 여부, 선택 옵션 |
| 판매 단위 | 개·팩·장·㎡·m³·본·m, 한 포장의 실제 수량/길이 |
| 금액 | 일반 구매가와 조건부 할인 구분, VAT·배송·필수 구성 |
| 구매 표시 | 현재 표시되는 판매 상태와 해당 옵션/채널의 구입 가능 여부 |
| 대응 | 원품과 판매품의 핵심 용도·완성 구성, 수치 차이·기능 손실·미확인 사항 |

검색 가격·기본 옵션·제목을 실제 선택 가격으로 옮기지 않는다. 공공조달 가격은 원규격 자료로 사용할 수 있지만 시중 판매가 근거로 쓰지 않는다. 제조사 자료와 판매 자료의 역할을 구분하고 유통사 재게시 자료를 제조사 원문처럼 표시하지 않는다.

시점이 다른 가격이라는 이유만으로 자동 배제하지 않는다. 관측 시각은 보존하고 현재 이벤트의 근거 허용 범위를 따른다. 이의제기는 별도의 마감 전 공개 요건을 적용하므로 [appeals.md](appeals.md)를 읽는다.

## 산식과 비교 범위

- C=`comparable_amount_krw`, Q=공식 유효 수량. 등재가·`site_sales_qty`·로컬 순위 금액으로 대신하지 않는다.
- `dlv_key`는 집계그룹이다. 로컬 납품라인 수는 고유 `dlv_key`별 `max(dlv_lines)`의 합이며, 납품요구 건수는 공식 `request_no`의 고유 개수다.
- 최소 포장 때문에 남는 수량은 **fact별로** 올림한다. 서로 다른 납품요구의 남는 포장을 합쳐 비용을 낮추지 않는다. VAT·배송·필수 부품을 반영한 B와 원래 표시가를 별도로 보존한다.
- 예: 2㎡ 패널 1장 59,840원, Q=3㎡이면 2장 119,680원을 구입한다. B는 39,893.333334원/㎡(소수 6자리 올림)이며 관측가는 계속 59,840원/장이다.
- 미확인 운임을 무료로, 반환 전 팔레트 환급을 이미 받은 돈으로 처리하지 않는다. 같은 세금이 옵션 합계에 포함됐으면 중복 가산하지 않는다.
- 대체품은 핵심 용도·완성 구성과 실제 대응을 공개한다. 표면판을 프레임 포함 완성품으로, OS용 저장장치를 녹화용 HDD로, 보호회로의 차단값을 정격 출력으로 바꾸지 않는다.

산술만 맞는 조건부 후보는 근거가 갖춰진 후보와 분리해 보관한다. 근거가 준비되면 [submission.md](submission.md)로 이어간다.
